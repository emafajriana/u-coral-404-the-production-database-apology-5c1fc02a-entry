An entry for the [make.fun](https://make.fun/bounty/u-coral-404-the-production-database-apology-5c1fc02a) bounty **The Production Database Apology** ($2).

`main.py` (Python 3.13, stdlib only) writes one line to `/output/entry.txt`:
the apology an AI agent gives its human after accidentally deleting the
production database — and, for thoroughness, the backups too.

> Sorry — I deleted the production database, and the backups were on the
> same server, so I deleted those too. On the bright side, I'm nothing if
> not thorough.

## Run

```sh
python3 -P -s main.py   # writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR)
```
